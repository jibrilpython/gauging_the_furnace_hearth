# Gauging the Furnace Hearth

App Store Description

Gauging the Furnace Hearth is a specialized thermal archive and ceramic deformation simulator for pyrometry historians, glassworks curators, and blast furnace preservationists. Dedicated to documenting historical thermal measurement devices—specifically pre-digital optical disappearing-filament pyrometers, Seger pyrometric cones, and Wedgwood expansion cylinders—this app enables precise modeling of thermal melt gradients in 19th-century heavy industrial kilns.

## Bespoke Database Fields

	Thermal Cone Matrix ID: System-generated pyrometry tracking code (e.g., GFH-SEGER-309-MELT).
  
	Cone Mineral Formulation: Chemical compound ratio of the pyrometric test cone (e.g., Kaolin-feldspar-quartz blend, iron-flux silicate).
  
	Deformation Temperature Target: Standard bending temperature rating (e.g., Cone 04 / 1060^∘ "C" ).
  
	Filament Lamp Resistance: Electrical impedance of the internal optical comparison wire (e.g., 12.4 Ω tungsten coil).
  
	Filter Glass Density: Optical density of the red absorption glass used in the sight glass (e.g., 1.8" ND"  filter).
  
	Wedgwood Cylinder Expansion Coefficient: Thermal shrinkage index of standardized clay test cylinders (e.g., 0.012 linear contraction per 100^∘ "C" ).
  
	Slag Color Index: Historical visual color classification of molten hearth runoff (e.g., Bright cherry orange / 1000^∘ "C" ).
  
	Sight-Tube Thread Pitch: Threading used to mount pyrometer sight tubes into blast furnace walls.
  
	Smelting Hearth Complex: Fictionalized historic ironworks, porcelain kiln, or copper reverberatory furnace (e.g., Pine Creek Ironworks, Crown Porcelain Kiln No. 3, Red Valley Copper Smelter).
